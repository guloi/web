## 操作方式

- <div>R</div>
    - 保存当前偏移 使用数字键加载  存档时会保存(不好用)


- <div>[ ] - = <br>
     -  移动地图 用于制作长地图
    </div>


- <div>方向键上/下(或鼠标滚轮) </div>
    -  切换瓦片


- <div>方向键左/右</div>
    - 旋转


- <div>WASD</div>
    - 用于微调（如果没用R键记下微调的X和Y的值 那么将难以使用V来选中并修改它！）


- <div>X</div>
    -  保存为编辑器格式的存档


- <div>C</div>
    - 加载存档


- <div>enter</div>
    -  保存为Comp类型的存档


- <div>M</div>
    -  格式刷 仅角度


- <div>K</div>
    - 格式刷 仅角度 用于复制指定瓦片角度 使用时需按下V键


- <div>V</div>
    -  选择已被放置的瓦片 并进行修改 （在G键非按下状态下使用 否则难以选中）
    <div>B  ->  在按下V时 旋转被选中的瓦片</div>
    <div>N  -> 在按下V时 旋转被选中的瓦片</div>
    <div>Z  -> 在按下V时 删除被选中的瓦片(包括重叠的)</div>
    <div>L  ->  在按下V时 将选中的瓦片的角度设置为使用M键或K键保存的角度</div>
    <div>H  -> 在按下V时 尝试将瓦片坐标修正为可被30整除的数(不可撤回) </div>
    <div>U  -> 在按下V时 选取选中的瓦片(如果使用了J键 此功能不可用！)</div>

- <div>E</div>
    - 重置微调带来的改变


- <div>G</div>
    - 直接以鼠标XY坐标来放置


- <div>Space</div>
    - 重置角度（已放置不做更改


- <div>Backspace</div>
    - 删除最后一个放置的瓦片


## 这里是CompREMAKE版的专属

- <div>T</div>
    - 保存为CompREMAKE版的存档文件


- <div>J</div>
    - 为这个瓦片添加碰撞白名单
